## How I work

I prefer to understand the existing system before changing it.

For maintenance and troubleshooting work, my usual process is:

1. Reproduce and isolate the problem.
2. Inspect the relevant code, database and infrastructure.
3. Identify the root cause instead of masking the symptom.
4. Implement the smallest reliable solution.
5. Validate the result and document important changes.

I am especially interested in projects where an existing PHP/backend application needs to be repaired, improved, migrated or connected to cloud and AI services.

---

## Current focus

**Backend first → Cloud infrastructure → AI & automation**

This reflects how I approach real systems: establish a reliable backend, provide solid infrastructure, and then introduce automation or intelligence where it makes sense.
